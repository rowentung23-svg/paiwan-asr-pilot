# Paiwan ASR Pilot Experiment｜排灣語語音辨識前導實驗

低資源排灣族語語音辨識（ASR）之前導可行性測試，為國立成功大學資訊工程學系博士班研究計畫
「低資源排灣族語語音辨識與 AI 輔助語言學習系統」的先期實驗，比較現有公開模型在自行錄製之
北排灣語語料上的辨識表現，作為後續方言特定微調與音素對齊研究的基準（baseline）。

## 研究動機

排灣族語屬於台灣瀕危原住民語言之一，現有公開語音辨識模型多以優勢語言為主，對排灣語（尤其
特定方言，如本實驗使用的北排灣布曹爾亞族腔）幾乎沒有針對性訓練或評估。本實驗的目的是在投入
博士班研究之前，先確認：（1）現有最好的公開模型在真實排灣語語料上的辨識水準大約落在哪裡；
（2）主要的錯誤類型與辨識難點是什麼，藉此決定後續研究要優先解決哪些問題。

## 比較模型

- **Whisper large-v3**（OpenAI，通用多語模型，零樣本、未針對排灣語微調）
- **FormosanBank/formosan-asr-paiwan**（現有公開的排灣語 ASR baseline 模型，以 XLS-R 53 微調）

## 實驗資料

自行錄製之北排灣語語料，發音人為家族成員（北排灣布曹爾亞族），內容涵蓋植物詞彙與日常問候
短句。**基於發音人隱私考量，原始音檔不公開於本 repo**，僅公開文字稿、程式碼與統計結果，
供方法與結果複現參考。

| 資料集 | 詞彙/句數 |
|---|---|
| 植物詞彙（單一發音人，混合中文/排灣語朗讀） | 55 詞 |
| 植物詞彙（切割音檔，純排灣語） | 55 詞 |
| 問候短句（切割音檔） | 10 句 |

## 實驗結果（WER／CER）

以「植物_pure_paiwan_切割音檔」逐筆切割評估為例：

| 資料集 | 模型 | 平均 WER | 平均 CER | 完全正確率 |
|---|---|---|---|---|
| 植物詞彙 | FormosanBank formosan-asr-paiwan | 52.73% | 12.32% | 49.09%（27/55） |
| 植物詞彙 | Whisper large-v3 | 149.09% | 68.98% | 3.64%（2/55） |
| 問候短句 | FormosanBank formosan-asr-paiwan | 21.83% | 4.67% | 50.0%（5/10） |
| 問候短句 | Whisper large-v3 | 99.17% | 58.81% | 0.0%（0/10） |

詳細數字請見 `results/` 資料夾中的完整報告。

## 主要觀察

- 現有排灣語專用模型（FormosanBank）辨識表現明顯優於通用模型 Whisper，但整體 WER 仍偏高，
  顯示對特定方言（本實驗為北排灣布曹爾亞族腔）仍有明顯改善空間。
- Whisper 幾乎無法正確辨識排灣語內容，僅能處理語料中夾雜的中文部分。
- `/q/` 音與喉塞音（glottal stop, `'`）是兩個模型共同的主要辨識難點。
- 本實驗尚未進行強制對齊（forced alignment）與音素層級分析，錯誤分類為初步規則判定，
  屬於 MVP／baseline 等級的可行性測試，非正式論文用數據。

## 對博士研究方向的意涵

本前導實驗確認了現有公開模型作為 baseline 的可行性與其限制，後續研究將透過方言特定語料
微調、音素層級強制對齊與錯誤分析，進一步降低 WER，並將這套評估流程延伸應用到 AI 輔助
族語口說學習系統的設計上。

## 檔案結構

```
paiwan-asr-pilot/
├── paiwan_asr_experiment.py     # 實驗一：三模型比較（單一長音檔，整段輸出 vs. 整份詞表）
├── paiwan_asr_mvp_colab.py      # 實驗二：MVP baseline，切割音檔逐筆評估（多發音人/多資料集）
├── data/
│   └── 植物篇_reference_transcript.txt   # 參考逐字稿（純排灣語，55 詞）
└── results/
    ├── ASR實驗摘要報告.txt
    └── paiwan_asr_mvp_summary_report.txt
```

## 執行方式

兩份程式皆設計於 Google Colab 環境執行（需開啟 GPU：執行階段 > 變更執行階段類型 > T4 GPU）：

1. 將整份 `.py` 貼到一個 Colab cell 並執行，或依程式內的 CELL 分段貼到多個 cell。
2. 依程式提示上傳所需的語料檔案（音檔因隱私考量不隨本 repo 公開，如需重現實驗請自行提供
   對應格式的音檔）。
3. 執行完成後會輸出 WER/CER 統計表與摘要報告。
